# Inlämning 2 – Enhet & Integration

Detta är en React TypeScript-app skapad med Vite som del av kursen i webbutveckling.

## 🧩 Komponenter

- `ColorChanger` – En ruta som ändrar färg vid klick.
- `ThemeToggler` – En knapp som byter mellan ljus och mörk färgskala, sparar valet i localStorage.

## 🚀 Starta projektet

```bash
npm install
npm run dev
